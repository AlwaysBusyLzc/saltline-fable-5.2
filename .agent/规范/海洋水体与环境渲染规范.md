# 海洋水体与环境渲染规范

## 1. 方案源流与架构
本项目海洋水体与体积云环境深度吸收 `https://gitee.com/tube-brother/vue3-threejs`（Spectral Ocean + Volumetric Atmosphere/Clouds）的图形学实现：
- **物理海洋频谱（Spectral Ocean）**：基于 Tessendorf 统计波浪学说，模拟真实物理重力波与涌浪（Swells）。
- **物理大气散射（Atmospheric Sky）与体积云（Volumetric Clouds）**：模拟太阳天顶角变化带来的 Rayleigh 瑞利与 Mie 米氏散射，搭配光线步进（Raymarching）渲染多层厚度云层。

## 2. 海洋水体技术规约
1. **波浪数学与置换（Wave Simulation）**：
   - 采用多波叠加坡度算法（Gerstner Waves）或 GPU FFT 快速傅里叶变换频谱计算。
   - 顶点着色器中对平面网格执行横向拉扯与纵向提升，形成尖锐波峰（Choppy Crests）与平缓波谷。
2. **法线与反射折射**：
   - 动态计算微表面法线向量，结合太阳方向计算双叶高光反射（Specular Highlights）。
   - 水体使用菲涅尔方程（Fresnel Equation）融合深海深蓝吸收色、近岸浅绿色与天空镜面反射。
3. **泡沫与浪尖破碎（Wave Foam & Crest Breaking）**：
   - 使用雅可比行列式（Jacobian Matrix）检测网格压缩极限，当压缩量超出阈值时计算破浪泡沫（Breaking Foam），配合衰减函数模拟海沫消散。
4. **浮力采样接口（Buoyancy Sampling API）**：
   - 必须提供 CPU/GPU 双端高度查询函数 `getWaterHeight(x, z, time)`，供物理系统与载具探针实时获取当前坐标下的浪高和水面法线倾角。

## 3. 体积云与天空系统规约
1. **物理天光模型**：
   - 自定义全屏天空着色器（Fullscreen Sky Shader），内置大气光学厚度计算与光晕（Aureole）渲染。
2. **多层体积云渲染**：
   - 使用 3D Worley/Perlin 噪声进行光线步进采样（Raymarching）。
   - 为避免中低端设备掉帧，采用自适应步长（Adaptive Step Size）或半分辨率渲染合成（Half-Res Upsample），确保移动和旋转视角下不掉帧。
