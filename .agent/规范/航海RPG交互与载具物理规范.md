# 航海RPG交互与载具物理规范

## 1. 角色与载具状态机设计

玩家在游戏中拥有三种核心存在形态，彼此之间能够无缝切换：

```
       [陆地徒步 (Foot)]
          │      ▲
(接触水面) │      │ (登上岸边/码头)
          ▼      │
     [水上滑板 (Skateboard)] <─────按 X 键切换 (仅限水面)
          │
  按 S 键 │ 再次按 S 或下船
          ▼
   [战船驾驶 (Ship)]
```

### 1.1 陆地徒步模式 (On Foot)
- **按键映射**：`W / A / S / D` 移动，`Shift` 加速奔跑，鼠标转动视角，`Space` 跳跃。
- **地形自适应**：角色脚底进行射线检测（Raycasting）或高度图采样，紧贴地面坡度；进入浅水区有减速效果。

### 1.2 水上滑板模式 (Water Skateboard - 按 X)
- **触发条件**：角色处于海面或浅水区域时按下 `X` 键。
- **物理特性**：
  - 高灵敏度：转向半径小，加速度高，最高速度约 25节 (Knots)。
  - 贴浪滑行：单点浮力采样，板身姿态跟随水波表面法线即时倾斜（Pitch & Roll）。
  - 水花尾流：在滑板后方发射程序化水花粒子群，速度越快尾流越长。

### 1.3 战船驾驶模式 (Ship Sailing - 按 S)
- **触发条件**：在海面上或码头泊位处按下 `S` 键，立即在水面上召唤生成古代战船（福船/宝船），角色自动站上艉楼舵位开始驾驶。再次按 `S` 键可收回船只切换回滑板或人形态。
- **物理特性**：
  - 航海惯性力学：具有质量和动量，加速慢、减速需打倒舵或落帆，具有较大的回转半径。
  - 多点浮力探针（4-Point Buoyancy Probes）：在船首、船尾、左舷、右舷分别采样波浪高度，通过四点高度差实时计算船体的俯仰（Pitch）、横摇（Roll）与升降浮沉（Heave）。
  - 船头劈浪与两侧水流特效。

## 2. 大地图与小地图系统 (Minimap - 按 M)
- **全屏/半屏大地图与右上角小地图**：
  - 默认右上角常驻雷达式小地图，实时显示玩家当前坐标、朝向、码头坐标、主岛与周边各岛礁。
  - **按下 M 键**：平滑呼出全尺寸战术航海图，支持拖拽漫游与标记，显示经纬度格网、航线指南针、泊位锚地和岛屿地形。
  - **海陆区域分色**：陆地用米黄色/绿色等高线着色，深水区用深靛蓝，近海礁石群与浅滩用浅青色。
